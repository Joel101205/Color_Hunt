# Color Hunt

A 2-player multiplayer game developed as part of a university project.

## Description

Color Hunt is a 1v1 multiplayer game where players compete to find and photograph objects matching a randomly assigned color.

* Players are matched into a 1v1 game and receive a random color.
* Players search their surroundings for an object matching the assigned color and take a picture of it.
* Points are awarded based on **color accuracy** and **time taken**.
* Players receive bonus points for taking their picture farther away from their starting position.
* The player with the most points wins the round.
* The winner is rewarded with colored pixels that can be placed on a shared global canvas.

## Technologies

* **Unity** — Game client, UI, and C# game logic
* **Firebase** — Authentication, Firestore database, and Cloud Functions
* **Unity Gaming Services** — Player authentication, player management, and friends functionality
